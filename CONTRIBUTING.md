# Contributing

Contributions are welcome, particularly compatibility tests with WLED and Switch models other than Mariko V2. Please reproduce changes with `bash scripts/test.sh` and a successful full Switch build before opening a pull request.

For changes to the VIC capture or launcher, document tested firmware and Atmosphère versions and keep a rollback procedure. Do not submit proprietary console keys, firmware binaries, personal console logs, or private network settings.
